# T5-Text-Summarization-FastAPI-Deployment

A text summarization project using the **T5 (Text-to-Text Transfer Transformer)** model to generate concise summaries from dialogue text. The trained model is deployed using **FastAPI** with a simple web interface.

## 🚀 Project Overview

This project demonstrates an end-to-end NLP workflow:

- Text preprocessing
- T5 Transformer model
- Model training and evaluation
- Saving the trained model
- FastAPI deployment
- Interactive web interface for generating summaries

## 🛠️ Technologies Used

- Python
- PyTorch
- Hugging Face Transformers
- T5
- FastAPI
- Uvicorn
- HTML
- Jupyter Notebook
